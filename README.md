Regulix Tools is the premier institutional launchpad, Block 0 bundler, and multi-wallet trading terminal engineered specifically for the **pump.fun** ecosystem on Solana. Rebranded from Regulus Tools to **Regulix Tools** ($RLIX).

## 🚀 Key Features

- **Atomic Block 0 Bundling**: Package token creation + initial buy orders inside an atomic Jito MEV bundle. Zero front-running or sniping risk.
- **200-Wallet Distribution**: Shard initial token supply across up to 200 holder wallets with customizable or randomized allocations to bypass bubble/cluster heuristics.
- **Unified Multi-Wallet Trading**: Watch real-time candlestick charts and execute synchronized Mass Buys and Mass Sells (25%, 50%, 100%) across all connected wallets simultaneously.
- **AI Project Studio**: Built-in Claude compute workflow to generate complete dApp landing pages, vector branding, X banners, and viral launch pitch copy.
- **Client-Side Non-Custodial Security**: 100% ephemeral memory execution. Private keys never leave the browser.
- **$RLIX Fee Waiver**: Holding &ge; 0.1% of $RLIX supply unlocks permanent 0% platform fees across all tools.
